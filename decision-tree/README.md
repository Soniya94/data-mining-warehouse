\# Decision Tree Classification



\## Overview

This project demonstrates Decision Tree classification using Scikit-learn.



\## Dataset

The project uses the Iris dataset to classify iris flowers into three species.



\## Techniques Used

\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- Decision Tree Classifier

\- Model evaluation

\- Decision Tree visualization



\## Project File

\- `Decision tree Algorithm Scikit.ipynb` — complete notebook containing the analysis, code, outputs, and visualization.
